# Общая база рекордов и отзывов (Supabase)

Игра хранит общую таблицу рекордов и отзывы тестировщиков в бесплатной базе [Supabase](https://supabase.com) (Postgres). Свой сервер не нужен: браузер обращается к REST API базы напрямую.

## Подключение (один раз)

1. Зарегистрируйтесь на <https://supabase.com> и нажмите **New project**. Название любое, регион ближайший (например, Central EU — Frankfurt). Пароль базы сохраните у себя, игре он не нужен.
2. Откройте **SQL Editor → New query**, вставьте содержимое [`schema.sql`](schema.sql) и нажмите **Run**. Появятся таблицы `records` и `feedback` с защитой.
3. Откройте **Project Settings → API** (или кнопку **Connect**) и скопируйте:
   - **Project URL**, вида `https://xxxx.supabase.co`;
   - **anon / publishable key**, публичный ключ.
4. Вставьте оба значения в [`src/config.js`](../src/config.js).

> ⚠️ Ключ **service_role / secret** никогда не кладите в игру и никому не пересылайте: он обходит всю защиту базы.

## Что защищает база

Anon-ключ виден любому в коде страницы, в Supabase так и задумано. Права ограничены политиками RLS в [`schema.sql`](schema.sql):

| Таблица | Читать | Добавлять | Менять / удалять |
|---|---|---|---|
| `records` | все | все | никто |
| `feedback` | только владелец в панели Supabase | все | никто |

Проверки CHECK отсекают мусор: имя длиннее 16 символов, очки выше 5000, пустой отзыв.

**Ограничение:** клиентская игра не может доказать, что очки честные. Подделать рекорд через API технически можно. Для игры с друзьями это приемлемо. Если таблицу начнут засорять, лишние строки можно удалить в панели Supabase (**Table Editor**).

## Где читать отзывы

**Table Editor → feedback** в панели Supabase. Там видны имя (если его оставили), оценка 1–5, текст и версия игры.
